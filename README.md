# Green Hope NGO Website

A multi-page website developed for **Prandhara Greenhope Foundation** to present its mission, projects, social initiatives, and opportunities for public participation.

## Overview

The website provides a centralized platform for displaying the foundation's information, projects, donation details, and volunteer opportunities. Development and improvements are ongoing.

## Features

- Home page and organizational information
- Mission and vision sections
- Projects and social initiatives
- Donation and donor information
- Volunteer registration and membership applications
- Contact and certificate-related pages
- Organized navigation across multiple pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
